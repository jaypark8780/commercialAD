## 제작 중 확인된 것

### 1. 부정 프롬프트가 역효과를 낸다

`soul_2`는 프롬프트의 부정어를 파싱하지 못합니다. 브랜드 규칙(§8-1 보라 배제)을 지키려고
`no purple, no violet`을 넣었더니 **"purple"이 유인어로 작용해 오히려 보라색이 대량 생성**됐습니다.
명찰, 노트북 메뉴바, 니트, 배경 스크린이 전부 보라로 나왔습니다.

**해결**: "purple"이라는 단어를 프롬프트에서 완전히 제거하고, 모든 색을 긍정 서술로 지정.

```
❌ charcoal sweater, no purple
⭕ dark charcoal grey knit sweater
❌ blank screen, no purple, no interface
⭕ full-screen black terminal filling the display edge to edge
   with no menu bar and no window chrome
```

같은 원리로 `no text`도 신뢰할 수 없습니다. 화면 속 글자는 **애초에 글자가 없는 화면**
(단색 발광, 추상 광선 바)으로 생성하고 실제 UI는 후반 합성해야 합니다.

### 2. 나이 지정이 흘러내린다

"late 30s"만 쓰면 백발 60대가 나옵니다. **숫자 나이 + 머리색을 함께 못박아야** 합니다.
`38 years old with short jet black hair` 형태로.

### 3. NSFW 오탐

문제될 내용이 없는 프롬프트(파티에서 폰을 든 남자)가 한 차례 NSFW로 차단됐습니다.
문장 구조를 바꿔 재제출하면 통과합니다. 재시도 비용은 무시할 수준입니다.

### 4. 채택률

43장을 생성해 14장을 채택했습니다. **채택률 약 33%** — 문서 §10-7이 전제한
10~15%보다 높습니다. 인서트는 대체로 한 번에 나왔고, 재작업은 거의 전부 인물 컷에서
발생했습니다(보라색 오염, 나이 이탈, 표정 불일치, 선배 성별 변경).

### 5. 얼굴은 텍스트로 고정되지 않는다 (가장 중요)

인물 묘사 문자열을 매 컷 동일하게 복붙했는데도 **컷마다 다른 사람이 나왔습니다.**
텍스트는 조명·의상·실루엣까지만 고정합니다.

| 시도 | 결과 |
|---|---|
| 텍스트 묘사 상수만 | ❌ 컷마다 다른 얼굴 |
| `soul_2` + 이미지 레퍼런스(`image` role) | ❌ 스타일 참조일 뿐, 정체성 미고정 |
| **Reference Element + `nano_banana_pro`** | ✅ **전 컷 동일 인물** |

Soul 학습 대신 Element를 택한 이유는 **샷 3·16에 두 인물이 한 프레임**에 들어가기 때문입니다.
Soul은 생성당 1명만 가능하고, Element는 한 프롬프트에 여러 개의 `<<<element_id>>>`를 넣을 수 있습니다.

부수적으로 알게 된 것: **파일명으로 내용을 추측하면 안 됩니다.** 업로드된
`gencow_young_bustcut_v2`를 "young = 청년"으로 넘겨짚고 후배 레퍼런스로 썼더니 여성이 나왔습니다.
검증 생성 한 번(약 0.3 크레딧)이면 확인되는 것을 추측으로 건너뛴 실수입니다.

## 캐릭터 확정 (GENCOW 키비주얼)

두 캐릭터 모두 제작사 제공 키비주얼의 실제 인물로 확정했습니다.
**조명·컬러·의상 명도 원칙은 그대로 유지**해 룩 시스템을 깨지 않았습니다 —
후배는 밝은 하늘색, 선배는 어두운 블랙으로 채도 대비가 유지됩니다.

히어로 컷(11)은 3테이크를 뽑아 비교했습니다.

| 테이크 | 판단 |
|---|---|
| A | ✅ **채택** — 정면 응시, 무표정한 입에 따뜻한 눈 |
| B | ❌ 손가락이 입을 가림 — 립싱크 컷으로 치명적 |
| C | ❌ 시선이 카메라를 벗어남 — 제4의 벽을 깨지 못함 |

탈락본은 Higgsfield 생성 기록에 남아 있습니다. 선배 얼굴이 GENCOW 키비주얼로 교체되면서
이 3테이크는 폐기됐지만, **판단 기준은 그대로 유효**합니다 — 히어로 컷은 입이 가려지면 안 되고
(립싱크), 시선이 카메라를 벗어나면 안 됩니다(제4의 벽).

부수 효과로 **샷 3의 표정이 개선**됐습니다. 남성 버전에서는 청년이 활짝 웃고 있어
"웃음이 불안으로 바뀌는" 시나리오와 어긋났는데, 재생성 때
`his smile collapsing into worry, eyebrows lifting anxiously`로 감정을 명시해 해결했습니다.
**표정은 형용사가 아니라 근육 움직임으로 서술**해야 합니다.
