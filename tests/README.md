# 히어로 컷 립싱크 테스트

`조언v1.0.md` §10-1이 최대 리스크로 지목한 **한국어 립싱크**의 실현 가능성 검증입니다.
샷 11–12(제4의 벽 파괴, "아직도 모르세요? 한방 되는데~")를 단독으로 만들었습니다.

이 컷이 안 나오면 시나리오 전체를 재설계해야 하므로, 나머지 16컷보다 먼저 검증했습니다.

| 파일 | 내용 |
|---|---|
| `11_히어로_립싱크테스트.mp4` | 5.04초 · 1926×1076 · 30fps · AAC 음성 포함 |
| `11_히어로_VO.wav` | 한국어 음성 단독 (4.18초, 24kHz) |
| `11_히어로_필름스트립.jpg` | 0.5초 간격 10프레임 |

## 제작 방법

```
① 한국어 VO 생성      seed_audio (ByteDance) · 프리셋 여성 보이스 "Vera"
② 오디오 구동 립싱크   wan2_7
                      start_image      = 확정된 히어로 스틸
                      audio_references = ①의 VO
```

**순서가 중요합니다.** 영상을 먼저 만들고 음성을 얹는 것이 아니라, **음성을 먼저 만들고
그 음성으로 입을 구동**합니다. `wan2_7`은 `audio_references`를 받아 발음에 입 모양을 맞춥니다.

- **비용**: 영상 17.5 + 음성 소액 = 약 18 크레딧

## 검증 결과

### 작동한 것

- **립싱크 발생** — 0.5초 오므린 입, 1.0초 열린 입, 2.0·2.5초 발화 등 프레임마다 입 모양이 뚜렷이 변합니다
- **정체성 유지** — 5초 내내 동일 인물. 골드 후프, 긴 다크 헤어, 얼굴 구조 모두 유지
- **조명 유지** — 좌측 키 + 우측 앰버 림이 시작 프레임 그대로 이어집니다
- **시선 고정** — 대부분의 프레임에서 카메라를 정면으로 봅니다

### 고쳐야 할 것

**1. 3.0초 이후 미소가 과합니다 (가장 중요)**

문서 §3-3은 *"한 번도 웃지 않지만 한 번도 차갑지 않을 것"*, 마지막에만 *"입꼬리가 아주 살짝"*
올라가라고 규정합니다. 현재 결과는 마지막 2초를 **활짝 웃으며** 보냅니다.

"아직도 모르세요?"를 웃으면서 말하면 **우월감으로 읽힙니다.** 이 광고가 실패하는
단 하나의 방식이 바로 그것입니다.

→ 다음 테이크 프롬프트: `lips stay closed and relaxed throughout, absolutely no smile,
only at the final half second the faintest asymmetric lift at one corner of the mouth`

**2. 0.5초에 눈이 감깁니다**

의도한 것은 중반의 느린 눈깜빡임 하나인데, 시작 직후에 시선이 내려갑니다.
제4의 벽을 깨는 컷에서 초반 시선 이탈은 효과를 약화시킵니다.

→ `she does not blink for the first two seconds, holding eye contact with the lens`

**3. 길이 정합**

VO 4.18초 / 영상 5.04초 — 남는 0.86초는 발화 후의 여백으로 쓸 수 있어 문제되지 않습니다.
오히려 "한방 되는데~" 뒤의 한 박자로 유용합니다.

## 검증하지 못한 것

**한국어 발음의 자연스러움과 싱크 정확도는 판단하지 않았습니다.**
프레임에서 확인 가능한 것은 입이 움직인다는 사실까지이고, 그 입 모양이 실제 한국어
음소와 맞는지, 프리셋 보이스의 한국어 억양이 어색하지 않은지는 **사람이 들어야** 합니다.

특히 확인이 필요한 지점:

- `seed_audio` 프리셋 보이스가 영어권 이름 기반입니다. 한국어 억양이 부자연스러울 수 있습니다
- **"한방 되는데~"의 말끝 물결표**가 살아 있는지 — 문서 §3-3에 따르면 이 어감 하나가 톤 전체를 결정합니다
- 38세 창업가의 목소리로 들리는지

억양이 어색하면 대안은 세 가지입니다.

1. 다른 프리셋 보이스로 재생성 (가장 저렴)
2. 실제 성우 녹음을 업로드해 `audio_references`로 사용 — **품질은 이 방법이 확실합니다**
3. `seed_audio`의 음성 클로닝(`audio_references`로 목소리 복제)

## 결론

**시나리오의 최대 기술 리스크는 해소되었습니다.** 한국어 오디오로 립싱크가 구동되고,
Element로 고정한 얼굴이 영상에서도 유지됩니다. 나머지 16컷은 립싱크가 필요 없으므로
(§10-1의 립싱크 예산 집중 전략) 기술적으로 더 쉽습니다.

남은 것은 연출 조정이며, 재생성 2~3테이크로 해결 가능한 수준입니다.
